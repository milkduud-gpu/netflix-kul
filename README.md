# netflix-kul

A Netflix-style app with a React front end (`front-end/`) and a Supabase database (`supabase/`).

## Run the front end
```
cd front-end
npm install
npm run dev
```

## Structure
- `front-end/` — React + Vite app
- `supabase/` — database schema, seed data and backups
